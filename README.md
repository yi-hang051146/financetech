# 金融科技期末分组报告（第 2 组）

武汉大学《金融科技学》2026 年秋季学期期末分组报告。题目：对上市公司年报做文本挖掘，提炼一个事件或因子，用 FF3 或 FF5 评估它的市场价值，或者检验这个因子是否被定价。

- 组别：第 2 组（8 人）刘佳宜、张雨萌、唐思沐、孙欣杰、汪一航、张婧、卢昱娇、李沐阳
- 陈述：12 月 9 日（第 14 周课）现场 20 分钟陈述加 10 分钟问答，带纸质报告
- 电子版：12 月 11 日前把报告、代码、数据发给助教
